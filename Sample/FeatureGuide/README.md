# A-mail 実画面 機能説明資料

`A-mail_実画面_機能説明資料.pdf` は、A-mail の実際の React UI を使ったスマートフォン向け縦型ガイドです。

## 掲載条件

- 画面は `browser demo provider` で起動した A-mail の実UIです。
- 表示内容はすべて架空のテストデータです。
- 実メール、外部AI、SMTP、実アカウント認証、送信処理は使用していません。
- 個人情報に見えるアカウント名・メールアドレス・リポジトリ名は、資料化前に架空値へ置換または画面外へ除外しています。
- 資料内では「確認済み」「未実装」「未確認」を分けて表記しています。

## ファイル

- `A-mail_実画面_機能説明資料.pdf`: 配布用PDF
- `pages/`: PDFを1080×1920相当でレンダリングした確認用PNG
- `screens/`: PDFに使用したプライバシー処理済みの実画面PNG
- `screen_manifest.json`: 画面取得条件と加工内容
- `process_screenshots.mjs`: 画面加工の再現スクリプト
- `build_feature_guide.py`: PDF生成スクリプト

## 現状の注意

- Gmail OAuth / XOAUTH2 は仕様上の目標であり、現在のアカウント追加画面はアプリパスワード方式です。
- ChatGPT接続UIはありますが、実アカウント・配布アプリでのログイン、生成、利用枠連携、終了時停止は実機受入前です。
- AIは返信候補までを作り、送信は利用者が最終確認して行う運用です。
