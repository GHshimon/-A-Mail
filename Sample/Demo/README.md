# A-mail Phase B スマホ向け架空デモ

スマホで操作設計を確認できる、縦型の無音デモです。登場人物、会社名、ID、利用率、メール本文はすべて架空です。実メール、実ChatGPT認証、実AI生成、実送信は行っていません。

## 成果物

- `phase-b-mobile-demo.mp4`: 1080 × 1920、約60秒、無音
- `phase-b-mobile-demo-overview.png`: 全体フローを1枚で確認する静止画
- `frames/`: 動画を構成する8場面のPNG
- `render_manifest.json`: 場面構成、表示時間、免責表示

## 示している流れ

1. テストメールを開き、内部IDで顧客・案件境界を固定
2. APIキーを登録せずChatGPTへ接続する動線
3. アカウント単位で返信下書きへの利用を明示的にON
4. 必要な文脈と文体プロファイルから返信候補を生成
5. 本人が宛先・根拠・言い回しを確認して本文へ反映
6. AIではなく本人が通常の送信操作を実行

最終場面では、実装済みの範囲と、配布アプリでまだ実機確認していない範囲を分けています。したがって、この動画はUI・運用設計の説明資料であり、本番接続の証跡ではありません。

## 再生成

```bash
./Sample/Demo/build_phase_b_mobile_demo.sh
```

描画は `sharp`、動画化は `ffmpeg` を使います。ローカルに `sharp` がない場合は、Codex同梱ランタイムのモジュールパスを自動利用します。
